# 응원 API

## 엔드포인트

| Method | Path | 인증 | 설명 |
|---|---|---|---|
| `POST` | `/v1/cheers/{friendId}` | 필요 | 친구에게 오늘의 응원을 보냅니다. |

## 업무 규칙

- 친구 관계인 사용자만 응원할 수 있습니다.
- 자기 자신을 응원할 수 없습니다.
- 같은 친구에게 하루 한 번만 응원할 수 있습니다.
- `friendId`는 친구 관계 ID가 아니라 상대 사용자의 ObjectId입니다.
- 성공 응답의 `date`와 `createdAt`을 기준으로 UI 상태를 갱신합니다.

## 주요 에러

- `CE001` (`409`): 오늘 이미 해당 사용자를 응원함
- `CE002`: 자기 자신을 응원함
- `FR001`: 친구 관계를 찾을 수 없음
