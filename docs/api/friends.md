# 친구 API

모든 엔드포인트는 일반 사용자 access token이 필요합니다.

## 엔드포인트

| Method | Path | 설명 |
|---|---|---|
| `POST` | `/v1/friends/invite-codes` | 새 초대코드를 생성합니다. |
| `GET` | `/v1/friends/invite-codes/{code}` | 친구 추가 없이 초대자 정보를 미리 조회합니다. |
| `POST` | `/v1/friends/by-invite/{code}` | 초대코드로 친구 관계를 생성합니다. |
| `GET` | `/v1/friends/me` | 내 친구 목록을 조회합니다. |
| `DELETE` | `/v1/friends/{friendId}` | 친구 관계를 삭제합니다. |

## 권장 호출 순서

1. 초대받은 코드를 `GET /invite-codes/{code}`로 검증하고 초대자 정보를 표시합니다.
2. 사용자가 확인하면 `POST /by-invite/{code}`를 호출합니다.
3. 성공 응답 또는 친구 목록 재조회 결과로 화면 상태를 갱신합니다.

초대코드 조회만으로는 친구가 추가되지 않습니다. 친구 관계는 양방향 관계로 취급하며 삭제 시 상대 사용자와의 관계도 제거됩니다.

## 주요 에러

- `IC001`: 초대코드를 찾을 수 없음
- `IC002`: 초대코드 만료
- `IC003`: 유효하지 않은 초대코드
- `IC004`: 자신의 초대코드 사용
- `FR001`: 친구 관계를 찾을 수 없음
- `FR002`: 이미 친구
- `FR003`: 자기 자신 추가
